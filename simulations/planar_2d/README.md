# Planar 2D Simulation Case

This folder contains supplementary simulation results for the planar tendon-driven continuum arm.

## Description

The planar case considers a continuum arm composed of three PCC segments. Each segment is actuated by an antagonistic tendon pair and controlled through its scalar curvature coordinate.

The simulation illustrates:

- curvature tracking for three independent reference trajectories,
- tendon tension profiles,
- motor shaft angle responses,
- animation of the planar soft arm motion.
