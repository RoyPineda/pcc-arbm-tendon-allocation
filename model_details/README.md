# Model Details

This folder contains additional model information associated with the PCC--ARBM formulations used in the paper:

**"A Control Allocation Strategy for Tendon-driven Arms Modeled Via the Augmented Rigid Body Approach"**

## Contents

- [Planar RPPR DH parametrization](./dh_planar_rppr.md)
- [Spatial RRPRRRRPRR DH parametrization](./dh_spatial_rrprrrrprr.md)

## Notes

The planar model uses a 4-link RPPR augmented chain for each PCC segment.

The spatial model uses a 10-link RRPRRRRPRR augmented chain for each 3D PCC segment.

These augmented rigid-body chains are not physical rigid mechanisms. They are modeling tools used to reproduce the geometry and dynamic properties of the corresponding constant-curvature soft segment within a rigid-body dynamics framework.
